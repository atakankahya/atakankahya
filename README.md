## Master's Thesis

### Reinforcement Learning for Spacecraft Magnetic Attitude Control

My master's thesis investigated **magnetorquer-only attitude control for small satellites**, combining classical spacecraft dynamics with reinforcement learning.

The work involved:

- Spacecraft attitude dynamics and environmental modelling
- Magnetic attitude control
- State estimation
- Classical control baselines
- Reinforcement learning with PPO
- Behavioural cloning
- MATLAB/Simulink, Python and C++/LibTorch simulation workflows

My main interest is at the intersection of **control theory, autonomous systems, aerospace, robotics, and high-performance engineering software**.
